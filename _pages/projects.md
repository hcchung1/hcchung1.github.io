## 🧠 LLaMA2 Fine-Tuning Pipeline

使用 PyTorch 與 Hugging Face 架設的 LLM 微調流程，支援 LoRA 與模型合併，並可進行 WikiLarge 語料實驗。

- 🛠 技術：Python, PyTorch, Transformers, PEFT, Accelerate
- 📎 [GitHub 連結](https://github.com/hcchung1/llama2-lora)
- 📝 支援多種 tokenizers 與 FP16 訓練模式

## 🧪 Capacitive Sensing Firmware Library

開發基於 IQS7222C 的 I2C 通訊 firmware library，並封裝於 ESP32 平台，支援實時觸控座標輸出。

- 🛠 技術：C/C++, ESP-IDF, I2C, Embedded Systems
- 📎 [TG0 Internship 應用成果](#)
- 📦 可被應用於多項電容感測產品開發

- 🛠 技術：Node.js, Flask, Web3.js, Solidity
